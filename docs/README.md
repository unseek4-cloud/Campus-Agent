## 文档检查与待确认项

### 已更正的文档矛盾

旧说明中出现第二套静态前端、/login 和 /admin 等旧页面、Element Plus/Axios、可信浏览器 history、“尚无鉴权/未实现 RAG”、每 1.5 秒政策轮询、缺重排直接拒答、机器固定账号/事项 ID/模型结果，以及不存在的测试脚本。当前说明已按代码更正。

数据库实际为 Spring SQL Init，V3–V12 自动建表，V2 针对早期旧列人工升级；依赖名、文件版本号和事项 version 均不能替代完整政策版本治理。准备清单已按账号隔离，分享范围与材料逐项校验也已实现，旧评审条目已标明状态。
