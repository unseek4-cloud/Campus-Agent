# 前端视觉优化与 Vue 合并

日期：2026 年 10 月 13 日。唯一维护入口为 `frontend/`；旧静态目录与旧 Vue 页面已清理。

本次采用中性色、细边框与克制的层次：删除品牌勾选装饰、侧栏字符图标、指标图标和彩色状态圆点；头像改为圆形姓名头像；发送按钮改为 SVG 箭头；单行、多行和手机输入框均使用对称的上下留白。概览、检索、办事、申请、管理、登录和分享共用同一组样式变量，并保留明暗主题。

Vue SFC 承载登录、外壳和问答布局，Vue Router 管理页面切换、浏览器前进后退、会话参数及公开分享地址。迁入的 API 和业务模块保留 Cookie/CSRF、消息 ID、幂等请求、权限范围、材料附件、步骤进度、分享和图片导出契约。进度直接引用原 TypeScript 模块，已移除重复生成脚本和未使用的 Element Plus、Axios 依赖。

验证使用构建后的实际 Vue 应用与拦截的后端 DTO：

- `npm run build`：类型检查及生产构建。
- `npm test`：28 项进度与回答渲染测试。
- `npm run test:browser`：123 项检查，覆盖问答/历史/分享/登录、材料上传/补交、管理员审核、学生和管理员页面、手机布局、输入框对称、浏览器返回与权限边界。
- 与优化后的静态版对比截图：浅色、深色问答首页逐像素一致；其余页面用相同数据、字体、尺寸和主题进行检查。
- Windows `start.ps1 -FrontendOnly -NoBrowser` 实测可启动、访问并退出前端；本机入口和代理使用 `127.0.0.1`，避免 localhost 解析超时。

浏览器测试数据为测试夹具，不代表实际学校政策。本次无需数据库迁移或修改后端服务。

启动及生产部署方式见 [前端说明](../frontend/README.md)。较早文档中的静态版入口、旧组件路径和测试命令属于历史记录，当前运行入口与验证命令以该说明为准。
