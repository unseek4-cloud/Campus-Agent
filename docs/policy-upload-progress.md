# 政策上传处理进度与自动完成提示

政策管理页上传文件后，在上传区域下方和文档列表中显示处理百分比、阶段和已处理页数。当前阶段采用中文说明：等待解析、解析文档、识别扫描内容、整理文本、生成索引数据和建立索引。

原问题是上传后只加载一次列表；进度请求仅在打开“查看”弹窗时启动，导致列表一直保留“处理中”。现在列表和详情共用一套轮询，约每两秒获取仍在处理的文档状态，关闭详情后列表仍会更新。

- Java 后端返回 `SUCCESS` 后显示 100% 和“解析成功，已建立索引”，同步更新已索引／处理中计数、分块数和操作按钮，并提示成功。
- 返回 `FAILED` 后显示错误原因，同步更新失败计数，并提示解析失败。
- 短暂断网后自动重试；慢请求不会叠加。任务结束、离开页面或退出登录后停止跟踪，过时响应不会修改其他页面。
- 重建索引会重新开始跟踪；重新打开政策管理页也会跟踪已有的处理中任务。

只显示后端返回的真实进度，完成状态以 Java 后端保存的最终结果为准。文件上传接口已返回完成状态时，页面直接展示最终结果。

## 启动与手工验收

三服务启动命令见 [启动说明](feedback-profile-acceptance.md#启动三个服务)。使用开发服务器时，刷新前端以加载新代码，再用管理员账号进入政策管理。

1. 上传一份新的 PDF 或 TXT。上传后应出现进度卡片，列表中的状态也应有进度条；无需打开“查看”。
2. 等待处理完成。卡片变为 100%，出现成功提示，列表显示“已索引”，处理中计数减一，分块数更新。
3. 处理过程中打开“查看”，确认详情进度也更新；关闭弹窗后继续等待，列表仍应自动完成。
4. 点击“重建索引”，确认进度从新任务的开始状态更新，并再次提示完成。
5. 处理失败时，应直接显示错误原因和失败提示。
